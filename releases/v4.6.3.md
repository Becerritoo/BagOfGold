# BagOfGold 4.6.3

## Highlights

- Flushes pending player balance updates during a clean server shutdown.
- Prevents recently changed balances from reverting to the previous periodic save after a restart.

## Compatibility

- Java 21.
- Paper 1.21.11 is the validated runtime.
- CustomItemsLib 1.2.0.

## Validation

- Maven clean package completed successfully.
- All 4 automated debt-policy tests passed.
- Runtime testing changed a balance and stopped the server before the periodic save.
- Shutdown wrote the pending balance to SQLite, and the next startup loaded the exact saved amount.
