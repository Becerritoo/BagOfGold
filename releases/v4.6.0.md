# BagOfGold 4.6.0

BagOfGold 4.6.0 is the first semantic release of the fork maintained by
[Becerritoo](https://github.com/Becerritoo). Rocologo remains credited as the
original author.

## Highlights

- Adds configurable bounded player debt.
- Uses available physical money before creating debt.
- Applies deposits to outstanding debt before crediting new cash.
- Includes net balances in Vault, per-world economy calls, placeholders, banker
  displays and wealth rankings.
- Migrates existing SQLite and MySQL balance tables automatically.
- Uses CustomItemsLib 1.2.0.
- Includes the maintained Paper, Towny, Shopkeepers, token-security and balance
  synchronization fixes from the earlier fork builds.

## Configuration

```yaml
economy:
  enable-player-debt: true
  maximum-player-debt: 10000.0
```

Set `enable-player-debt` to `false` to reject withdrawals that exceed available
cash.

## Compatibility

- Java 21.
- Paper 1.21.11 is the validated runtime.
- CustomItemsLib 1.2.0.
- MobHunting 8.6.1 is the validated MobHunting build at publication time.

BagOfGold, CustomItemsLib and MobHunting use independent semantic versions. Their
compatible versions are documented with each release.

## Validation

- Maven clean package completed successfully.
- All automated debt-policy tests passed.
- Paper 1.21.11 testing covered startup, database migration, physical-money
  synchronization, balance changes and clean shutdown.
