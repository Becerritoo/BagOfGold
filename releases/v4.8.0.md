# BagOfGold 4.8.0

BagOfGold 4.8.0 adds safe, configurable physical-money prices to admin
Shopkeepers and moves maintained update checks to Hangar.

## Highlights

- Converts renamed paper in the exact form `bagofgold 3000` into a signed Shopkeepers price template.
- Binds the signed template to the Shopkeeper UUID and keeps it separate from real currency items.
- Withdraws the exact amount from loose money, bundles and carried shulker boxes.
- Splits larger bags and returns change through the existing physical-currency flow.
- Rejects copied, modified or manually inserted templates.
- Limits template creation to operators through `bagofgold.shopkeepers.template`.
- Replaces Spiget update checks with reviewed, stable and checksum-verified Hangar releases.

## Compatibility

- Java 21.
- Paper 1.21.11 is the current validation target.
- CustomItemsLib 1.4.0 is required.
- Shopkeepers 2.28.1 is the current validation target.
- MobHunting 8.7.1 is the companion development release.

## Validation

- All automated tests pass.
- Complete-stack startup and Shopkeepers integration registration pass on Paper 1.21.11.
- The update command handles the unpublished Hangar project without errors.
- In-game template creation, purchase, change and cancellation tests are pending.
